## 🚀 Quick Setup & Deployment to GitHub

### 1. Create a new repository on GitHub:
* Go to [GitHub.com/new](https://github.com/new)
* Repository name: e.g., `elite-executives-audit` or `elite-executives-client-portal`
* Keep it **Public** (or **Private** if you only want to view it yourself)

### 2. Push this folder to your GitHub repository:
Open your terminal inside this folder and run:

```bash
git init
git add .
git commit -m "Initial commit: Elite Executives Month 2 QA Portal & Report"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

## 🌍 Enable Free Live Web Link via GitHub Pages

To make the review portal accessible to anyone via a live web link:
1. In your GitHub repository, go to **Settings** $\rightarrow$ **Pages** (left sidebar).
2. Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. In about 30 seconds, GitHub will give you your live URL:
   `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/`
